# Form Takip

Telefon dostu antrenman ve beslenme takip uygulaması. Tek sayfa, kurulum gerektirmez.

- Kişisel plan: hedef, seviye, salon/ev, diyet tercihleri
- Set set antrenman kaydı, rekor ve hacim başarıları
- Haftalık menü, alışveriş listesi, kalori/protein/su takibi
- Hareket görselleri, haftalık özet

Veriler yalnızca kullanıcının kendi tarayıcısında (localStorage) saklanır. Hesap ya da sunucu yok.

iPhone: Safari → Paylaş → Ana Ekrana Ekle.

Kalori değerleri yaklaşıktır; tıbbi tavsiye değildir.
